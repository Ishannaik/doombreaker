01 / HOW IT BREAKS

One meter. Four stages. Full break.

A shared damage meter d runs from 0 to 1. Scrolling feeds it. Idle heals it. Each threshold adds a new layer of breaking.

The page softens. Blur creeps in, color drains to grayscale, darkness closes from the edges.

Procedural cracks spider across the screen. The page tears and glitches in hard cuts.

Everything shakes. The tremor scales with the damage, from a shiver to full violence.

A network-level rule blocks the feed. Scrolling returns nothing until you heal below 0.85.

02 / THE EFFECTS

03 / WHERE IT WORKS

Everywhere. Including the places you check the most.

Precise rules for the big feeds, a generic fallback for everything else.

Per-site rules live in a remote config and refresh every 6 hours, so the extension keeps working when sites change their internals. Shorts and Reels damage ~3× faster than scrolling, per video watched.

05 / FAQ

The wall, explained.

Does it lock me out of websites?

No. There are no lockouts and no guilt modals. The page breaks visually, and at full damage the feed stops loading, but you can always close the tab or stop scrolling to heal.

Does it work on every website?

Yes. Precise rules for X/Twitter, Reddit, Instagram, YouTube Shorts, and LinkedIn, plus a generic fallback for every other site based on wheel scrolling.

Does it track me?

No. The extension sends no data anywhere. No analytics. The only network call is a periodic refresh of the per-site configuration from the project's GitHub repo.

Does it break regular YouTube videos?

No. Only YouTube Shorts are affected. Regular videos are untouched.

What happens at full damage?

The page shakes, and a network-level rule blocks the feed from loading. Scrolling returns nothing until the damage heals below 0.85.

Is it free and open source?

Yes. MIT licensed on GitHub, with unit tests and an automated ship-verification suite.

06 / INSTALL

Arm the page.

DoomBreaker is not on the Chrome Web Store yet. Install it as an unpacked extension in two minutes.

  1. Open chrome://extensions and enable Developer mode (top-right switch).
  2. Click Load unpacked and select the doombreaker folder from the repo.
  3. Done. The popup gives you per-site toggles, brutality, presets, heal speed, and the daily limit.
